## ⭐ Proyectos destacados

### 🤖 [ollama-copilot-vscode](https://github.com/pilahito/ollama-copilot-vscode) — Local Copilot

Copilot **gratis y local** para VS Code con **Ollama**:

| Modo | Para qué |
|------|----------|
| 💬 Chat | Ideas y sugerencias |
| 🎓 Profesor | Aprender código |
| 😈 Ayudante | Agente que escribe archivos, terminal, internet y Ollama Build |

Detecta tu hardware (RAM/GPU) y recomienda modelos al instalar.

```bash
code --install-extension pilahito.local-copilot
ollama pull qwen2.5-coder:14b
```

### 🐧 [turing-smart-screen-linux](https://github.com/pilahito/turing-smart-screen-linux)

Fork mejorado para **Linux/Ubuntu** — mini pantalla Turing USB, 42+ temas, autostart, NVIDIA.

```bash
git clone https://github.com/pilahito/turing-smart-screen-linux.git
cd turing-smart-screen-linux && ./scripts/install-ubuntu.sh
```

### 🎣 [fishrewards-packs](https://github.com/pilahito/fishrewards-packs)

Packs YAML corregidos para **FishRewards** en Paper 26.1 (efectos válidos, validador + deploy Docker).
